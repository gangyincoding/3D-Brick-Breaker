# 3D打砖块游戏 - 物理引擎增强版

一个完全由鼠标控制的沉浸式3D打砖块游戏，采用Three.js构建，具备精确的物理碰撞检测和真实的物理效果。

## 🎮 游戏特色

### 核心玩法
- **鼠标控制**：移动鼠标控制挡板，点击发射球体
- **3D环境**：完全沉浸式的3D游戏场景
- **物理引擎**：遵循真实物理定律的碰撞和运动系统
- **动态难度**：随着游戏进行，球速逐渐增加
- **特殊砖块系统**：三种独特功能的特殊砖块，增加游戏策略性

### 特殊砖块
- **👯 分身砖**：击中后球数量翻倍，最多4个球同时游戏
- **📏 扩展砖**：击中后挡板长度增加，提升接球成功率
- **🧹 清扫砖**：击中后立即清除场上所有砖块，快速通关

### 视觉效果
- **粒子系统**：砖块破碎时的爆炸粒子效果
- **碰撞波纹**：挡板碰撞时的动态波纹效果
- **球体轨迹**：球体运动时的发光拖尾效果
- **3D光照**：多重光源营造立体感

### 物理效果
- **精确碰撞检测**：球体与挡板/砖块/边界的精确碰撞计算
- **动态反弹角度**：挡板不同位置碰撞改变球的反弹方向
- **重力模拟**：真实的重力影响和抛物线运动轨迹
- **能量损失**：碰撞时的能量衰减和摩擦力模拟

## 🎯 游戏机制

### 挡板控制系统
- 挡板宽度：10单位（增强操控性）
- 响应速度：实时跟随鼠标移动
- 碰撞区域：完整覆盖球体接触面
- 反弹角度：基于碰撞位置的动态计算

### 球体物理属性
- **半径**：0.5单位
- **初始速度**：0.25单位/帧
- **重力影响**：0.0015单位/帧²
- **最大速度**：动态限制防止失控

### 砖块系统
- **布局**：动态布局，根据难度调整行数和列数
- **颜色系统**：7种彩虹色渐变
- **特殊砖块**：三种功能各异的特殊砖块
- **普通砖块**：10分基础分值
- **金色砖块**：10%概率出现，50分

### 特殊砖块机制
- **分身砖**：简单模式1个，中等模式2个，困难模式3个
- **扩展砖**：每关1个，挡板长度+2单位，最大25单位
- **清扫砖**：每关1个，清除所有砖块包括特殊砖块
- **策略分布**：分身砖和扩展砖在前三排，清扫砖在最后两排

### 得分机制
- 普通砖块：10分
- 金色砖块：50分
- 特殊砖块：20分
- 连击奖励：连续击中砖块获得额外分数
- 速度提升：每破坏10块砖，球速增加8%

### 物理引擎算法
```javascript
// 精确碰撞检测算法
function checkSphereCollision(sphereCenter, sphereRadius, boxCenter, boxSize) {
    const closestPoint = new THREE.Vector3(
        Math.max(boxCenter.x - boxSize.x/2, Math.min(sphereCenter.x, boxCenter.x + boxSize.x/2)),
        Math.max(boxCenter.y - boxSize.y/2, Math.min(sphereCenter.y, boxCenter.y + boxSize.y/2)),
        Math.max(boxCenter.z - boxSize.z/2, Math.min(sphereCenter.z, boxCenter.z + boxSize.z/2))
    );

    const distance = sphereCenter.distanceTo(closestPoint);
    return distance < sphereRadius;
}

// 反射定律计算
function calculateReflection(velocity, normal) {
    const dotProduct = velocity.dot(normal);
    return velocity.sub(normal.multiplyScalar(2 * dotProduct));
}
```

## 🎮 操作说明

### 基本操作
1. **移动挡板**：鼠标左右移动
2. **发射球体**：鼠标点击
3. **重新开始**：游戏结束后点击重新开始按钮

### 游戏策略
- **角度控制**：利用挡板边缘改变球的角度，覆盖更多区域
- **优先级策略**：优先破坏分身砖和扩展砖，获得游戏优势
- **清扫时机**：在砖块较多时使用清扫砖，获得最大收益
- **多球管理**：分身后注意控制多个球，避免全部失误
- **挡板扩展**：合理利用扩展砖增加挡板长度，提高接球率
- **速度控制**：注意球速变化，及时调整反应速度
